АФЛ — КАК ПОЛУЧИТЬ ANDROID-ПРИЛОЖЕНИЕ (APK)
============================================

На твоём Mac сборка не идёт (Java 25). APK собирается на GitHub.

ВАРИАНТ A — БЫСТРО БЕЗ APK (уже работает)
-----------------------------------------
На телефоне Android:
  Chrome → открыть сайт АФЛ → меню ⋮ → «Установить приложение»
Это и есть приложение на главный экран.


ВАРИАНТ B — НАСТОЯЩИЙ APK ЧЕРЕЗ GITHUB (облако)
----------------------------------------------
1) Зарегистрируйся / войди на https://github.com

2) New repository → имя например: afl-android
   Public → Create (БЕЗ галочки README, если загружаешь свои файлы)

3) Загрузи ВСЮ папку из архива AFL-ANDROID-CLOUD-BUILD.zip
   (package.json, www/, .github/, capacitor.config.json и т.д.)
   в КОРЕНЬ репозитория.

   Удобно через сайт GitHub:
   Add file → Upload files → перетащи все файлы → Commit

   Или через git, если умеешь.

4) Вкладка Actions → workflow «Build Android APK»
   → Run workflow → Run workflow

5) Подожди 3–10 минут (зелёная галочка)

6) Открой этот запуск → Artifacts → скачай AFL-android-apk
   Внутри app-debug.apk

7) Перекинь APK на телефон → Установить
   (разрешить установку из неизвестных источников)


ВАЖНО
-----
• В репозитории должен быть файл www/index.html
• Файл .github/workflows/build-android.yml — уже в архиве
• Первый запуск может быть долгим
• APK debug — для лиги и тестов; для Google Play нужна отдельная подпись


ЕСЛИ ACTIONS НЕ ЗАПУСКАЕТСЯ
----------------------------
Settings репозитория → Actions → General → Allow all actions
